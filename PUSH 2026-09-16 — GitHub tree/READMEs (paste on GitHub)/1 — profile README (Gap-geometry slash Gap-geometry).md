# Gap Geometry

Exploring the geometry beneath information.

---

This is the public home for the Gap Geometry framework — independent research on one number, the gap, G = 1 − √2·ln 2 ≈ 0.019742: the complement of the ratio of the geometric to the logarithmic mean on the doubling interval, held as an object with its own exact series and certified bounds, and the places it turns up across published mathematics and physics.

Three principles run through the work: every number is verifiable at stated precision, every document says what kind of document it is, and every change is documented in plain view. There is no editorial gate other than the mathematics itself.
